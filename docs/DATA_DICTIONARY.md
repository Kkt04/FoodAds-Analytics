# Data Dictionary

All data is generated by `src/generate_data.py` and is **simulated**. Same seed = same data.

## advertisers (300 rows by default)
| Column | Type | Description |
|---|---|---|
| advertiser_id | text (PK) | e.g. ADV0001 |
| advertiser_name | text | Made-up restaurant name |
| category | text | Biryani, Pizza, Burgers, Chinese, North Indian, South Indian, Desserts, Beverages, Healthy, Fast Food |
| city_tier | text | Metro, Tier-1, Tier-2 |
| advertiser_size | text | SMB, Mid, Chain |
| signup_date | text (YYYY-MM-DD) | About 35% signed up before the data window opens (Jul 2025) |
| churn_date | text | Empty if the advertiser never churned in the window |

## campaigns (about 450 rows)
| Column | Type | Description |
|---|---|---|
| campaign_id | text (PK) | e.g. CMP00001 |
| advertiser_id | text (FK) | Owner |
| placement | text | Search Top, Home Banner, Cart Page, Category Listing, Sponsored Carousel |
| start_date, end_date | text | Campaign flight |

## daily_performance (about 86k rows, one per campaign per active day)
| Column | Type | Description |
|---|---|---|
| date | text | Day |
| campaign_id | text (FK) | |
| impressions, clicks, orders | integer | Funnel counts (clicks <= impressions, orders <= clicks) |
| spend | real | INR paid by the advertiser (= impressions x CPM / 1000) |
| attributed_revenue | real | INR order value attributed to the ads |

## inventory (1,825 rows = 365 days x 5 placements)
| Column | Type | Description |
|---|---|---|
| date, placement | text | |
| capacity_impressions | integer | Ad slots available that day (driven by platform traffic) |

## ab_test_users (60,000 rows)
| Column | Type | Description |
|---|---|---|
| user_id | text (PK) | |
| variant | text | `control` or `treatment` (Bestseller badge) |
| clicked, ordered | integer 0/1 | Did the user click the ad / order after clicking |
| order_value | integer | INR, 0 if no order |

## Patterns planted in the simulation (so you know what the analysis should find)
| Pattern | Where it shows up |
|---|---|
| Low-AOV categories (Desserts, Beverages) earn low ROAS | Query 03, 09 |
| Healthy converts worse in Tier-2 | Query 09 (small segment, noisy) |
| Home Banner: high CPM, low CTR, low fill, low ROAS | Query 04, 05 |
| Cart Page and Search Top: high intent, strong ROAS | Query 04 |
| Weekend (Fri-Sun) and festive-season (Oct-Nov) traffic uplift | Daily data (group `daily_performance` by weekday to see it) |
| Platform traffic grows 2.5% per month; CPM drifts up 0.6% per month | Query 02 |
| SMB advertisers churn most | Query 07, 08 |
| Bestseller badge lifts CTR by about 20% (relative) | A/B test |
| Search Top reaches near-capacity in the latest months (about 90% of June days were >=85% sold); Home Banner never does | Query 05 |
